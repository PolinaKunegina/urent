# Бот партнёрской сети

Телеграм-бот на своём сервере DigitalOcean. Он делает две вещи:

1. **Каждое утро присылает руководителям сводку по таблице воронки**: сколько лидов в работе,
   с кем касания сегодня и завтра (по фамилиям, с форматом и комментарием «что происходит»),
   у кого не запланировано следующее касание (красный флажок), где дата записана так,
   что её нельзя распознать.
2. **Считает часы по процессам из чата партнёров.** Партнёры пишут отчёт с хэштегами
   `#знакомство`, `#прогрев`, `#сделка`, бот складывает часы по каждому партнёру и добавляет
   их в утреннюю сводку: кто сколько занимался знакомством с экосистемой, прогревом и сделками,
   кто вчера не отчитался.

```
Партнёры ──(до 19:00)──► Таблица воронки на Google Drive ──┐
Партнёры ──(хэштеги)───► Чат партнёров в Telegram ─────────┤
                                                            ▼
                                      Бот на дроплете DigitalOcean (Docker)
                                                            │ 09:00
                                                            ▼
                                     Наталья, Кир, Антон: утренняя сводка
```

Таблицу партнёры заполняют как раньше, ничего конвертировать не нужно: бот читает и загруженный
`.xlsx`, и обычную Google Таблицу. Если у каждого партнёра своя копия таблицы, их можно
перечислить в `SHEETS`, и сводка покажет каждого отдельно плюс общий итог.

## Пример утренней сводки

```
📊 Воронка партнёрской сети — вт, 3 ноября

Петрова
Лидов в работе: 5 (отказов: 1)
📅 Касания сегодня, 03.11: 1
  • Котова Вера — касание 2, Zoom
    Ждёт демо личного кабинета
➡️ Завтра, 04.11: 1
  • Лисина Ада — касание 1
🔴 Без запланированного касания: 2
  Орлов Пётр, Семён Гусев
⚠️ Не распознана дата: Семён Гусев (касание 2: «вчера»)
Статусы: без статуса — 4, Касание 1 — 1

⏱ Часы по процессам за 02.11 (из чата)
  • Петрова: знакомство 2 ч · прогрев 1,5 ч · сделки 0,5 ч = 4 ч
  🔕 Не отчитались: Иванова
За 7 дней по всем: знакомство 9 ч (45%) · прогрев 7 ч (35%) · сделки 4 ч (20%)
```

## Правила для таблицы, чтобы сводка была точной

Бот берёт лист «Воронка лидов» и сам находит колонки по заголовкам (`Имя лида`, `Дата N-го касания`,
`Формат`, `Текущий статус`, `Описание, что происходит`), поэтому порядок колонок можно менять.

- **Следующее касание планируется датой в следующей свободной колонке «Дата N-го касания».**
  Касание сегодня или позже бот считает запланированным; если все даты в прошлом, лид попадает в 🔴.
- Дата пишется как `03.11.2026` или выбирается в календаре ячейки. Слова вроде «вчера» бот
  не угадывает и покажет их в ⚠️.
- Лиды со статусом, где есть слово «Отказ», в работу не считаются
  (настраивается в `EXCLUDE_STATUS_REGEX`).

## Эталон отчёта в чат партнёров

```
#отчет #план_Фамилия
#знакомство 2 ч — презентация экосистемы для Котовой, показала личный кабинет
#прогрев 1,5 ч — переписка с Соколовой, отправила 2 кейса
#сделка 30 мин — Жуков: согласовали пакет, ждём оплату
```

Часы можно писать как `2 ч`, `1,5 часа`, `40 мин`, `1:30`. Подходит и нумерованный формат
«1. Знакомство — 1 ч…», если в сообщении есть хотя бы один процессный хэштег. Отредактированное
сообщение бот пересчитывает. `#план_Фамилия` достаточно указать один раз, дальше бот запомнит
партнёра по его аккаунту. Отчёт принят, если бот поставил реакцию ✍; на 🤔 он подскажет, где не хватает часов.

## Команды

| Команда | Что делает |
|---|---|
| `/report` | сводка прямо сейчас (только руководителям) |
| `/hours 7` | часы по процессам за N дней по каждому партнёру |
| `/template` | эталон сообщения для партнёров |
| `/myid` | id чата и пользователя, нужен для настройки |

## Запуск на DigitalOcean

Понадобится около 40 минут. Хватит самого маленького дроплета (Ubuntu 24.04, 1 GB RAM).

**1. Бот в Telegram.** В [@BotFather](https://t.me/BotFather): `/newbot` и сохранить токен.
Затем `/setprivacy` → выбрать бота → **Disable**. Без этого бот в группе не видит обычные
сообщения с хэштегами.

**2. Доступ к таблице через сервисный аккаунт Google.**
1. [console.cloud.google.com](https://console.cloud.google.com) → создать проект.
2. «APIs & Services» → «Library» → включить **Google Drive API**.
3. «IAM & Admin» → «Service Accounts» → создать аккаунт → «Keys» → «Add key» → JSON. Скачается файл ключа.
4. Скопировать email сервисного аккаунта (`…@….iam.gserviceaccount.com`) и **поделиться с ним
   таблицей с правами «Читатель»**. Делает владелица файла, то есть тот, кто создал таблицу.

**3. Сервер.**
```bash
ssh root@IP_ДРОПЛЕТА
curl -fsSL https://raw.githubusercontent.com/PolinaKunegina/urent/main/partner-bot/deploy/setup_droplet.sh | bash
# пока код не слит в main, ставим из рабочей ветки:
# B=claude/bot-system-digital-ocean-sgzg6q
# curl -fsSL https://raw.githubusercontent.com/PolinaKunegina/urent/$B/partner-bot/deploy/setup_droplet.sh | BRANCH=$B bash

nano /opt/urent/partner-bot/.env              # токен, SHEETS, время отчёта
# с компьютера: scp ключ.json root@IP_ДРОПЛЕТА:/opt/urent/partner-bot/secrets/service-account.json
cd /opt/urent/partner-bot && docker compose up -d --build
docker compose logs -f
```

**4. Получатели.** Наталья, Кир и Антон пишут боту `/start`, затем `/myid`, и их `user_id`
вносятся в `REPORT_CHAT_IDS` через запятую. Бота добавляют в чат партнёров, там тоже `/myid`,
и `chat_id` (начинается с `-100`) идёт в `PARTNERS_CHAT_ID`. После правки `.env`:
`docker compose up -d`.

**Проверить доступ к таблице без Телеграма:**
```bash
docker compose run --rm partner-bot python -m bot.report
```

**Обновление:** `bash /opt/urent/partner-bot/deploy/update.sh`.

Часы из чата хранятся в `data/bot.db` (SQLite). Папка подключена как том, поэтому данные
переживают перезапуски и обновления. Для резервной копии достаточно скопировать этот файл.

## Для разработчиков будущего дашборда

Бот можно считать прототипом и источником требований:

- логика воронки (что считается «в работе», «запланировано», «без плана») находится в `bot/analytics.py`;
- разбор отчётов партнёров и хранилище часов: `bot/hashtags.py`, таблица `entries`
  (`partner, process, hours, note, day`). Её можно читать напрямую или выгружать в CSV;
- тесты (`pytest`) показывают ожидаемое поведение на примерах.

## Разработка

```bash
pip install -r requirements.txt pytest
pytest
python -m bot.report --file путь/к/Воронка.xlsx --date 2026-11-03
```
