# Бот партнёрской сети

Партнёры ведут своих клиентов и часы работы в общей Google Таблице — это их CRM.
Бот на своём сервере DigitalOcean читает таблицу, напоминает заполнить её и присылает
руководителям аналитику. Схема по ТЗ от 3 ноября (встреча Антона, Натальи и Полины).

## Таблица

Одна Google Таблица, у каждого партнёра **своя вкладка** с его именем:

- **слева — клиенты (CRM):** имя, контакт (по желанию: ник, телефон или почта), откуда пришёл, **следующий шаг: дата, что, время в минутах и этап**
  (привлечение / прогрев / закрытие), текущий статус (выпадающий список), что происходит,
  история касаний тройками «дата / формат (этап) / мин». Шаг уходит в историю сам — это делает
  Apps Script из `apps-script/Code.gs` (его вставляют в таблицу вручную, один раз и после каждого изменения).
  **Красным** подсвечивается клиент без следующего шага в ближайшие 7 дней: шаг не назначен,
  просрочен или дальше недели (кроме отказов и закрытых сделок: «оплатил пакет 240 / стал ментором»);
- **справа — часы по дням** (ссылка «→ к моим часам» вверху вкладки): план по привлечению,
  прогреву и закрытию пишет партнёр, **факт часов и людей считают формулы** (SUMIFS/COUNTIFS по минутам
  и этапу в истории касаний этого дня) + комментарий. Даты до 31 декабря, сегодня — зелёным,
  завтра — голубым, будущие дни с уже назначенными шагами — серым.
  Новые колонки на существующих вкладках бот добавляет сам при ближайшей синхронизации
  (одним атомарным batchUpdate) и обновляет «Инструкцию».
  Заголовки и даты защищены: их правит только бот и владелец таблицы.

Служебные листы:
- **Оглавление** — список партнёров со ссылками на их вкладки;
- **Сводка** — бот обновляет раз в час: активность, клиенты без касания, часы за 7 дней и с начала месяца;
- **Партнёры** — справочник: имя (как называется вкладка), @ник в Telegram, как ещё пишут.
  Новый партнёр добавляется строкой сюда — через час у него появится вкладка и ссылка в оглавлении.

**Песочница** — вторая таблица с такой же структурой для новичков на первые две недели
(чтобы они не видели чужие контакты). Подключается командой `/setsandbox ссылка`;
в отчётах новички помечены 🌱.

Таблицы живут по московскому времени (бот выставляет это сам): от этого зависит, что такое
«сегодня» в подсветке.

## Что присылает бот

| Когда | Кому | Что |
|---|---|---|
| 08:00 | руководителям в личку | клиенты без касания в ближайшие 7 дней по каждому партнёру; кто не внёс клиентов; часы за вчера — факт (план); кто не заполнил факт; активность каждого партнёра 🟢🟡🔴 |
| 08:00, пн | им же | итоги недели: часы по процессам за неделю и с начала месяца по каждому партнёру |
| 18:30 | в чат партнёров | напоминание заполнить таблицу до 19:00 и кто ещё не заполнил факт |
| 18:30 | партнёру в личку | его клиенты без касания, касания завтра, заполнен ли факт за сегодня и план на завтра, ссылка на его вкладку |

**Активность** партнёра — среднее из двух долей за последние 7 дней (в первую неделю — с даты
запуска): дни, когда заполнен факт часов, и клиенты, у которых есть касание в ближайшие 7 дней.
🟢 от 80%, 🟡 от 50%, 🔴 ниже.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | подключиться (без этого бот не может написать в личку) |
| `/mine` | партнёры | своя сводка и ссылка на свою вкладку |
| `/guide` | все | как вести таблицу |
| `/report` | руководители | утренняя сводка сейчас |
| `/week` | руководители | итоги последних 7 дней |
| `/status` | руководители | проверка: таблицы, кто не нажал Start, привязан ли чат |
| `/bindchat` | руководители | отправить в чате (или теме) партнёров — туда пойдут напоминания |
| `/setsheet ссылка` | руководители | подключить основную таблицу |
| `/setsandbox ссылка` | руководители | подключить песочницу |

## Установка

1. **Бот:** [@BotFather](https://t.me/BotFather) → `/newbot`, сохранить токен.
2. **Доступ Google:** в [Google Cloud Console](https://console.cloud.google.com) проект → включить
   Google Drive API и Google Sheets API → сервисный аккаунт → ключ JSON. Таблице (и песочнице)
   дать доступ **Редактор** на email сервисного аккаунта.
3. **Сервер** — в DigitalOcean: дроплет → Web Console, вставить:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/PolinaKunegina/urent/main/partner-bot/deploy/install.sh | bash
   ```
   Пока код не в `main`: `B=claude/bot-system-digital-ocean-sgzg6q; curl -fsSL https://raw.githubusercontent.com/PolinaKunegina/urent/$B/partner-bot/deploy/install.sh | BRANCH=$B bash`.
   Скрипт спросит токен, ссылку на таблицу, ники руководителей и JSON-ключ.
4. В Telegram: руководители и партнёры жмут Start, в чате партнёров — `/bindchat`, проверка — `/status`.

Сервер каждые 5 минут сверяется с GitHub и сам перезапускает бота с новым кодом.
Ручное обновление: `bash /opt/urent/partner-bot/deploy/update.sh`.

Первичное создание вкладок из старой воронки (разложить клиентов по партнёрам):
```bash
docker compose run --rm partner-bot python -m bot.setup_sheet <SHEET_ID> --prefill-from "Воронка лидов"
```
